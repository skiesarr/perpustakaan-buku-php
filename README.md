# Perpustakaan Buku (PHP + MySQL)

Aplikasi CRUD sederhana untuk data buku: tambah, lihat, edit, dan hapus.

## Fitur
- Tambah buku
- Lihat daftar buku
- Edit data buku
- Hapus buku (dengan konfirmasi)

## Cara menjalankan
1. Jalankan Apache dan MySQL di XAMPP
2. Import `perpus.sql` lewat phpMyAdmin
3. Taruh `buku.php` di `C:\xampp\htdocs\`
4. Buka `localhost/buku.php`
